Game Description

PERYA KNIGHTS is a dice arcade game made in Python and Pygame, built around the booth games you'd actually see at a Philippine perya. There are seven modes total. Some are straight up betting games like Color Game and Baccarat, and some are party modes you play with friends for free with no credits involved. Every round uses the same six dice dropped into a 3D tumbler machine, so whether you're betting against the house or going head to head with another player, it's still the same roll deciding everything. Your credits, win streaks, and past rounds all carry over while you play, so it never really resets until you want to.

Game Concept

It started out as a plain dice rolling game, roll, see the number, move on. The enhancement was turning that into an actual perya experience. Same six dice, same tumbler, but now every mode has its own identity, from Color Game and Baccarat as the classic betting rounds to MA IBA TAYA, HULING TATAYO, and SABONG NG DAIS as the group party modes. Building seven modes off one shared dice engine meant the core roll had to be completely fair no matter which game was running on top of it. The Knights part just comes from framing each round like a duel instead of a plain bet. Makes losing sting a little less when it's a joust and not just bad luck.

🇺🇭 Filipino Theme

Perya booths are everywhere during fiestas and school fairs back home. Dice and color betting stalls, someone yelling out the odds, small bets but a big crowd around it. That's the actual heart of this game, the six colored dice, the tumbler, the shouting when someone wins. PERYA KNIGHTS just takes that booth energy and dresses it up like a small tournament, so a round of Baccarat or a match of SABONG NG DAIS feels like a contest instead of just gambling.

Play / Access

Perya Knights is built with Python + Pygame and doesn't run directly in a browser, but it's playable both on Android and on PC.

📱 On Android

  1. Download Perya_Knights_V_2.0.apk (button above) to your phone.
  2. Allow "install from unknown sources" if prompted, then open the APK to install.
  3. Launch Perya Knights from your app drawer and play.
An older build, Perya_Knights_V_1.0.apk, is also available if you need it for comparison.

💻 On PC

  1. Download and unzip PeryaKnights.zip (button above).
  2. Make sure Python 3.11+ is installed, then install Pygame:
    pip install pygame
  3. Open a terminal inside the PeryaKnights folder and run:
    python main.py
Controls: mouse for everything, F11 for fullscreen, H for how-to-play, SPACE to roll / play again, ESC to go back.
